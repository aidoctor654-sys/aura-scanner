## Co to jest

Aura Scanner to **natywna aplikacja Android** zbudowana bez Android Studio/Gradle.
Cały build odbywa się w Termux na ARM64 przy użyciu ~300MB toolchainu.

## Feature'y

- ✅ **Kamera** — getUserMedia() w WebView z secure origin
- ✅ **Canvas animacja** — skanowanie z pulsing light
- ✅ **7 kolorów aury** — Gold, Violet, Blue, Green, Red, White, Orange
- ✅ **i18n** — EN/PL z pełnymi tłumaczeniami
- ✅ **Scroll** — opis aury przewijany touch
- ✅ **Debug panel** — 5 tapów na 🇵🇱 PL = logi JS
- ✅ **Share** — PNG card via Android Intent (w toku fixów)

## Build Pipeline

### Wymagania

```bash
pkg update
termux-change-repo  # wybierz grimler.se (NJU ma 404)
pkg install openjdk-21 ecj dx aapt apksigner

# android.jar API 30
mkdir -p android-sdk/platforms/android-30
curl -L -o android-sdk/platforms/android-30/android.jar \
  "https://raw.githubusercontent.com/Sable/android-platforms/master/android-30/android.jar"
```

### Build (jedna komenda)

```bash
export ANDROID_JAR="$PWD/android-sdk/platforms/android-30/android.jar"

# 1. Generate R.java
aapt package -f -m -J src/ -S res/ -I "$ANDROID_JAR" -M AndroidManifest.xml --auto-add-overlay

# 2. Compile Java
javac --release 8 -cp "$ANDROID_JAR" -d build/ src/com/aurascanner/*.java

# 3. DEX (Java → Dalvik)
jar cvf classes.jar -C build/ .
dx --dex --min-sdk-version=26 --output=classes.dex classes.jar

# 4. Package APK
aapt package -f -F aura.apk -I "$ANDROID_JAR" -M AndroidManifest.xml -S res/
aapt add aura.apk classes.dex
aapt add aura.apk assets/www/index.html

# 5. Sign
apksigner sign --ks debug.keystore --ks-pass pass:android --key-pass pass:android aura.apk
```

## Kluczowe lekcje

### `file://` vs `https://localhost/`

`getUserMedia()` wymaga secure origin. W WebView `file://` nie działa.

```java
// ❌ NIE DZIAŁA — file:// nie jest secure origin
webView.loadUrl("file:///android_asset/www/index.html");

// ✅ DZIAŁA — localhost = secure origin
String html = loadAssetHtml("www/index.html");
webView.loadDataWithBaseURL("https://localhost/", html, "text/html", "UTF-8", null);
```

### User Gesture dla kamery

Android wymaga żeby `getUserMedia()` był wywołany z kliknięcia, nie automatycznie.

```javascript
// ❌ NIE DZIAŁA — brak user gesture
document.addEventListener('DOMContentLoaded', initCamera);

// ✅ DZIAŁA — wywołane z onclick
scanBtn.addEventListener('click', () => { initCamera(); startScan(); });
```

### Zatrzymywanie kamery

Kamera działa w nieskończoność jeśli nie zatrzymasz streamu.
Zielona kropka w UI Androida = kamera zajęta = share może failować.

```javascript
function stopCamera() {
  if (stream) {
    stream.getTracks().forEach(track => track.stop());
    stream = null;
  }
  video.srcObject = null;
}
// Wywołaj po skanie i przy "Scan Again"
```

### Share w Android WebView

`navigator.share()` nie istnieje w WebView. Używaj JS Bridge:

```javascript
// JS: generate canvas → Base64 → native bridge
AuraNative.shareImage(canvas.toDataURL('image/png'));

// Java: decode Base64 → file → Intent.ACTION_SEND
@JavascriptInterface
public void shareImage(String base64Data) {
    byte[] bytes = Base64.decode(base64Data.split(",")[1], Base64.DEFAULT);
    File file = new File(getCacheDir(), "aura-card.png");
    // ... write ... then Intent share
}
```

### Runtime Permissions (Android 6+)

Manifest deklaruje, ale musisz też prosić w runtime:

```java
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
    if (checkSelfPermission(Manifest.permission.CAMERA) != PackageManager.PERMISSION_GRANTED) {
        requestPermissions(new String[]{Manifest.permission.CAMERA}, 1001);
    }
}
```

### Reload otwiera browser

`shouldOverrideUrlLoading()` musi pozwolić na `localhost`:

```java
public boolean shouldOverrideUrlLoading(WebView view, String url) {
    if (url.contains("localhost")) return false;  // Keep in WebView
    if (url.startsWith("http://") || url.startsWith("https://")) {
        startActivity(new Intent(Intent.ACTION_VIEW, Uri.parse(url)));
        return true;
    }
    return false;
}
```
